---
title: Runtime Adapters
description: Reference for Redop's portable fetch handler and Bun, Node, Cloudflare, and Vercel adapters.
---

Redop is Bun-first. `.listen()` still starts a long-running Bun HTTP server by default. Portable deployments use `app.handler()` plus a thin runtime adapter.

## `app.handler(opts?)`

Returns a Web-standard fetch function:

```ts
type HttpFetch = (
  request: Request,
  runtime?: {
    waitUntil?: (promise: Promise<unknown>) => void;
    disableIdleTimeout?: (req: Request) => void;
  }
) => Promise<Response>;
```

`HandlerOptions` accepts the HTTP knobs from `ListenOptions` without bind fields: `path`, `health`, `cors`, `debug`, `sessionTimeout`, `listCache`, `maxBodySize`.

## Package exports

| Export | Purpose |
| ------ | ------- |
| `@redopjs/redop` | Full API + Bun `.listen()` |
| `@redopjs/redop/cloudflare` | `toCloudflare(app)` Workers handler |
| `@redopjs/redop/vercel` | `toVercel(app)` / `toVercelEdge(app)` |
| `@redopjs/redop/node` | `listenNode`, `toNodeListener`, `toNodeFetch` |

## After-response scheduling

| Runtime | How `afterResponse` is kept alive |
| ------- | --------------------------------- |
| Bun / Node (long-lived) | `queueMicrotask` |
| Cloudflare Workers | `ctx.waitUntil(...)` via `toCloudflare` |
| Vercel / Edge | pass `waitUntil` from `@vercel/functions` into `toVercel(app, { waitUntil })` |

## Capability matrix

| Capability | Bun `.listen()` | Node | Cloudflare | Vercel / Edge |
| ---------- | --------------- | ---- | ---------- | ------------- |
| Stateless MCP `2026-07-28` | yes | yes | yes | yes |
| Reliable `afterResponse` | yes | yes | via `waitUntil` | via `waitUntil` |
| Legacy sessions + GET SSE | yes | yes | limited | limited |
| Long `subscriptions/listen` SSE | yes | yes | hard | hard |

## Examples

```ts
// Cloudflare
import { toCloudflare } from "@redopjs/redop/cloudflare";
export default toCloudflare(app);

// Vercel
import { toVercel } from "@redopjs/redop/vercel";
import { waitUntil } from "@vercel/functions";
export default toVercel(app, { waitUntil });

// Node
import { listenNode } from "@redopjs/redop/node";
listenNode(app, { port: 3000, hostname: "0.0.0.0" });
```
